# Shopping List V1

A simple personal shopping-list app built with React + TypeScript + Vite.

## Features
- Multiple shopping lists
- Add item, quantity, expected price, optional category
- Mark items as purchased
- Enter actual price
- Expected vs actual totals
- Shopping history
- LocalStorage persistence
- Mobile-first layout

## Run locally
1. Install Node.js 20+
2. Open a terminal in this folder
3. Run:
   npm install
   npm run dev
4. Open the local address shown by Vite

## Important
This is V1. There is no login, cloud database, sharing, AI, retailer integration, or payment system yet.
